# Angular Web Application

A web application built with **Angular and TypeScript**, featuring authentication, form validation, CRUD functionality, and API integration.

## Features

* User authentication
* Protected routes
* CRUD operations
* Form validation
* Responsive UI
* API integration

## Tech Stack

* Angular
* TypeScript
* RxJS
* JSON Server
* HTML / CSS

## Getting Started

### Installation

```bash
npm install
```

### Run the application

```bash
ng serve
```

The application will be available at `http://localhost:4200`.

### Run the mock API

This project uses JSON Server as a local mock backend.

```bash
json-server --watch db.json
```

The API will run at `http://localhost:3000`.

## Authentication

Authentication is implemented using the local JSON Server API. It is used to simulate a backend environment for development and demonstration purposes.

For a production application, authentication would be handled by a proper backend or authentication service with secure credential and session management.
